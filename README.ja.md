## ⬇️ ダウンロード

最新ビルドは **[Releases](https://github.com/hihi-team/pet-nunu-info/releases/latest)** から。お使いのシステムに合ったファイルを選んでください。

| システム | ファイル | インストール |
|---|---|---|
| 🍎 **macOS** 14+ | `Petnunu-macOS-*.dmg`（または `.zip`） | `.dmg` を開く → **Petnunu.app** を **Applications** にドラッグ |
| 🪟 **Windows** 10/11 | `Petnunu_*-setup.exe`（または `.msi`） | インストーラーを実行 → 次へ → 完了 |
| 🐧 **Linux**（X11） | `Petnunu_*.AppImage` · `.deb` | AppImage: `chmod +x` して実行 · `.deb`: `sudo dpkg -i` |

### 初回起動時

- **macOS** — アプリは **Developer ID で署名され、公証（notarize）済み**なので、普通のアプリと同じようにダブルクリックで開けます。Gatekeeper の警告は出ません。
- **Windows** — SmartScreen が *「Windows protected your PC」* と表示することがあります → **More info → Run anyway**（コード署名証明書はまだ購入していません）。
- **Linux** — **X11** が一番安定します。**GNOME Wayland** をお使いの場合は **「Xorg/X11」** セッションでログインしてください。ペットの位置指定と常に最前面表示が正しく動作します。

**動作環境:** macOS 14 (Sonoma) 以降 · Windows 10/11 · X11/XWayland で動く Linux デスクトップ。

## ✨ 機能

- 🐣 **デスクトップペットのオーバーレイ** — 歩く・跳ぶ・眠る、画面の端をよじ登ってしがみつく、カーソルを追いかける、好きな場所へドラッグ。
- 💖 **お世話と感情** — ごはん、なでなで、あそぶ、寝かしつけ。happiness / energy / hunger / affection のステータス付き。
- 🪙 **コイン・クエスト・実績** — デイリーミッション、実績、コインウォレット。
- 🍅 **ポモドーロと集中モード** — 休憩 / 水分補給 / 目の休憩のリマインド、集中の統計（日次・週次・連続記録）。
- 🛒 **Pet Store** — コインで新しいペットをアンロック。
- 🌱 **育ててレベルアップ** + コミュニティのリーダーボード。
- 🎨 **Petnunu Studio** — 自分だけのペットを作成。
- 📦 **自作ペットパックのインポート**。
- 🖥️ **マルチモニター**、トレイ／メニューバー、オンボーディング、サウンド。

> アカウント・コインウォレット・ストア・ペットパックは **3 つのプラットフォームで共通**です。

## ❓ よくある質問

**アプリはオープンソースですか？**
ビルドはここで公開していますが、ソースコードは非公開です。このリポジトリはアプリを配布するためのものです。

**Windows/Linux 版には macOS 版の機能がすべてありますか？**
サーバー、アカウント、ウォレット、ペットパックの形式は共通です。macOS 版（Swift）が最初にできたもので、Windows/Linux 版（Tauri）は完全な同等機能へ向けて開発を進めています。

**自分の言語に対応していますか？**
ウェブは 22 言語に対応しています。Windows/Linux アプリは英語＋ベトナム語、macOS アプリは今のところ英語のみです。

**お金はかかりますか？**
ダウンロードも利用も無料です。アプリ内の一部アイテムはコインで購入できます。

**バグを見つけた／アイデアがある**
このリポジトリで **[Issue](https://github.com/hihi-team/pet-nunu-info/issues)** を立ててください。
