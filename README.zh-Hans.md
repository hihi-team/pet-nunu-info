## ⬇️ 下载

到 **[Releases](https://github.com/hihi-team/pet-nunu-info/releases/latest)** 获取最新版本，然后按你的系统选择对应文件：

| 系统 | 文件 | 安装方式 |
|---|---|---|
| 🍎 **macOS** 14+ | `Petnunu-macOS-*.dmg`（或 `.zip`） | 打开 `.dmg` → 把 **Petnunu.app** 拖进 **Applications** |
| 🪟 **Windows** 10/11 | `Petnunu_*-setup.exe`（或 `.msi`） | 运行安装程序 → 下一步 → 完成 |
| 🐧 **Linux**（X11） | `Petnunu_*.AppImage` · `.deb` | AppImage：`chmod +x` 后运行 · `.deb`：`sudo dpkg -i` |

### 首次启动

- **macOS** —— 应用已**使用 Developer ID 签名并通过公证**，双击即可像普通应用一样打开，不会出现 Gatekeeper 警告。
- **Windows** —— SmartScreen 可能提示 *"Windows protected your PC"* → **More info → Run anyway**（我们还没有购买代码签名证书）。
- **Linux** —— 在 **X11** 上支持最好。若使用 **GNOME Wayland**，请登录 **"Xorg/X11"** 会话，宠物才能正确定位并保持置顶。

**系统要求：** macOS 14 (Sonoma)+ · Windows 10/11 · 运行 X11/XWayland 的 Linux 桌面。

## ✨ 功能

- 🐣 **桌面宠物悬浮层** —— 走路、跳跃、睡觉，攀爬并挂在屏幕边缘，跟随光标，随手拖到任何位置。
- 💖 **照顾与情绪** —— 喂食、抚摸、陪玩、哄睡；happiness / energy / hunger / affection 各项数值。
- 🪙 **金币、任务与成就** —— 每日任务、成就、金币钱包。
- 🍅 **Pomodoro 与专注模式** —— 休息 / 喝水 / 护眼提醒，专注统计（每日、每周、连续天数）。
- 🛒 **Pet Store** —— 用金币解锁更多宠物。
- 🌱 **养成宠物升级** + 社区排行榜。
- 🎨 **Petnunu Studio** —— 创作属于你自己的宠物。
- 📦 **导入你自己的宠物包**。
- 🖥️ **多显示器**、托盘 / 菜单栏、新手引导、音效。

> 你的账号、金币钱包、商店和宠物包在**三个平台之间通用**。

## ❓ 常见问题

**这个应用开源吗？**
构建版本在这里公开发布；源代码保持私有。本仓库的作用是分发应用。

**Windows/Linux 版本有 macOS 版的全部功能吗？**
它们共用同一套服务器、账号、钱包和宠物包格式。macOS 版（Swift）诞生最早；Windows/Linux 版（Tauri）正在一步步补齐到完全一致。

**支持我的语言吗？**
网页端支持 22 种语言。Windows/Linux 应用提供英文 + 越南语；macOS 应用目前仅支持英文。

**需要付费吗？**
下载和使用都免费。部分应用内物品可以用金币购买。

**发现问题 / 有好点子？**
在本仓库提交 **[Issue](https://github.com/hihi-team/pet-nunu-info/issues)**。
