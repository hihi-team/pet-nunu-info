# 🐾 Petnunu

**Ein virtuelles Haustier, das auf deinem Desktop lebt — macOS · Windows · Linux.**

Dein Pet läuft herum, springt, klettert an den Rändern deines Bildschirms und macht ein
Nickerchen in einem transparenten Fenster, das über allen Apps schwebt — gesteuert aus der
Menüleiste, mit Pomodoro und Fokusmodus, damit sich Arbeit ein bisschen leichter anfühlt.

## ⬇️ Download

Hol dir den neuesten Build von den **[Releases](https://github.com/hihi-team/pet-nunu-info/releases/latest)** und wähle die Datei für dein System:

| System | Datei | Installation |
|---|---|---|
| 🍎 **macOS** 14+ | `Petnunu-macOS-*.dmg` (oder `.zip`) | `.dmg` öffnen → **Petnunu.app** in **Applications** ziehen |
| 🪟 **Windows** 10/11 | `Petnunu_*-setup.exe` (oder `.msi`) | Installer starten → weiter → fertig |
| 🐧 **Linux** (X11) | `Petnunu_*.AppImage` · `.deb` | AppImage: `chmod +x`, dann starten · `.deb`: `sudo dpkg -i` |

### Erster Start
- **macOS** — die App ist **mit einer Developer ID signiert und notarisiert**, sie öffnet sich also wie jede normale App (Doppelklick), ganz ohne Gatekeeper-Warnung.
- **Windows** — SmartScreen zeigt eventuell *„Windows protected your PC"* → **More info → Run anyway** (wir haben noch kein Code-Signing-Zertifikat gekauft).
- **Linux** — am besten unterstützt wird **X11**. Unter **GNOME Wayland** meldest du dich am besten in einer **„Xorg/X11"**-Sitzung an, damit sich das Pet richtig positionieren und immer im Vordergrund bleiben kann.

**Voraussetzungen:** macOS 14 (Sonoma)+ · Windows 10/11 · ein Linux-Desktop mit X11/XWayland.

## ✨ Funktionen

- 🐣 **Desktop-Pet-Overlay** — läuft, springt, schläft, klettert und hängt sich an Bildschirmränder, folgt deinem Mauszeiger, und du ziehst es überall hin.
- 💖 **Pflege & Gefühle** — füttern, streicheln, spielen, zudecken; Werte für happiness / energy / hunger / affection.
- 🪙 **Münzen, Quests & Erfolge** — tägliche Missionen, Erfolge, Münzbörse.
- 🍅 **Pomodoro & Fokusmodus** — Erinnerungen an Pausen, Trinken und Augenentspannung, Fokus-Statistiken (täglich, wöchentlich, Serien).
- 🛒 **Pet Store** — schalte mit Münzen weitere Pets frei.
- 🌱 **Ziehe Pets groß und steigere ihr Level** + eine Community-Bestenliste.
- 🎨 **Petnunu Studio** — erstelle dein eigenes Pet.
- 📦 **Importiere eigene Pet-Packs**.
- 🖥️ **Mehrere Monitore**, Tray bzw. Menüleiste, Einführung, Sound.

> Dein Konto, deine Münzbörse, der Store und deine Pet-Packs werden **auf allen drei Plattformen gemeinsam genutzt**.

## ❓ FAQ

**Ist die App Open Source?**
Die Builds werden hier öffentlich veröffentlicht, der Quellcode bleibt privat. Dieses Repository dient dazu, die App zu verteilen.

**Können die Windows/Linux-Builds alles, was macOS kann?**
Sie teilen sich denselben Server, dasselbe Konto, dieselbe Börse und dasselbe Pet-Pack-Format. Der macOS-Build (Swift) kam zuerst; der Windows/Linux-Build (Tauri) arbeitet sich Schritt für Schritt zur vollen Parität vor.

**Wird meine Sprache unterstützt?**
Das Web spricht 22 Sprachen. Die Windows/Linux-App kommt mit Englisch + Vietnamesisch, die macOS-App ist vorerst nur auf Englisch.

**Kostet das etwas?**
Herunterladen und Nutzen ist kostenlos. Manche Gegenstände in der App kannst du mit Münzen kaufen.

**Einen Fehler gefunden / eine Idee?**
Eröffne ein **[Issue](https://github.com/hihi-team/pet-nunu-info/issues)** in diesem Repository.
