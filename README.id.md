## ⬇️ Unduh

Ambil build terbaru dari **[Releases](https://github.com/hihi-team/pet-nunu-info/releases/latest)**, lalu pilih file yang sesuai dengan sistemmu:

| Sistem | File | Pemasangan |
|---|---|---|
| 🍎 **macOS** 14+ | `Petnunu-macOS-*.dmg` (atau `.zip`) | Buka `.dmg` → seret **Petnunu.app** ke **Applications** |
| 🪟 **Windows** 10/11 | `Petnunu_*-setup.exe` (atau `.msi`) | Jalankan installer → next → selesai |
| 🐧 **Linux** (X11) | `Petnunu_*.AppImage` · `.deb` | AppImage: `chmod +x` lalu jalankan · `.deb`: `sudo dpkg -i` |

### Saat pertama kali dibuka
- **macOS** — aplikasi ini **ditandatangani dengan Developer ID dan dinotarisasi**, jadi terbuka seperti aplikasi biasa (klik dua kali), tanpa peringatan Gatekeeper.
- **Windows** — SmartScreen mungkin menampilkan *"Windows protected your PC"* → **More info → Run anyway** (kami belum membeli sertifikat code-signing).
- **Linux** — paling optimal di **X11**. Di **GNOME Wayland**, masuklah ke sesi **"Xorg/X11"** supaya peliharaan bisa menempatkan diri dan tetap berada di atas jendela lain.

**Kebutuhan:** macOS 14 (Sonoma)+ · Windows 10/11 · desktop Linux yang menjalankan X11/XWayland.

## ✨ Fitur

- 🐣 **Overlay peliharaan desktop** — berjalan, melompat, tidur, memanjat dan bergelayut di tepi layar, mengikuti kursor, bisa diseret ke mana saja.
- 💖 **Perawatan & emosi** — beri makan, elus, ajak main, selimuti; statistik happiness / energy / hunger / affection.
- 🪙 **Koin, misi & pencapaian** — misi harian, pencapaian, dompet koin.
- 🍅 **Pomodoro & mode fokus** — pengingat istirahat / minum air / mengistirahatkan mata, statistik fokus (harian, mingguan, streak).
- 🛒 **Pet Store** — buka peliharaan baru dengan koin.
- 🌱 **Rawat peliharaan sampai naik level** + papan peringkat komunitas.
- 🎨 **Petnunu Studio** — buat peliharaanmu sendiri.
- 📦 **Impor paket peliharaan buatanmu sendiri**.
- 🖥️ **Multi-monitor**, tray / menu bar, onboarding, suara.

> Akun, dompet koin, toko, dan paket peliharaanmu **dipakai bersama di ketiga platform**.

## ❓ FAQ

**Apakah aplikasinya open source?**
Build-nya dipublikasikan di sini secara terbuka; kode sumbernya tetap privat. Repo ini ada untuk mendistribusikan aplikasi.

**Apakah build Windows/Linux punya semua fitur yang ada di macOS?**
Keduanya memakai server, akun, dompet, dan format paket peliharaan yang sama. Build macOS (Swift) lahir lebih dulu; build Windows/Linux (Tauri) sedang menuju paritas penuh.

**Apakah bahasa saya didukung?**
Webnya berbicara dalam 22 bahasa. Aplikasi Windows/Linux hadir dengan bahasa Inggris + Vietnam; aplikasi macOS untuk saat ini hanya bahasa Inggris.

**Apakah ada biayanya?**
Mengunduh dan memakainya gratis. Sebagian item di dalam aplikasi bisa dibeli dengan koin.

**Menemukan bug / punya ide?**
Buka **[Issue](https://github.com/hihi-team/pet-nunu-info/issues)** di repo ini.
