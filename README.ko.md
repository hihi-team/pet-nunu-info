## ⬇️ 다운로드

**[Releases](https://github.com/hihi-team/pet-nunu-info/releases/latest)** 에서 최신 빌드를 받은 뒤, 사용 중인 운영체제에 맞는 파일을 선택하세요:

| 운영체제 | 파일 | 설치 방법 |
|---|---|---|
| 🍎 **macOS** 14+ | `Petnunu-macOS-*.dmg` (또는 `.zip`) | `.dmg` 열기 → **Petnunu.app** 을 **Applications** 로 끌어다 놓기 |
| 🪟 **Windows** 10/11 | `Petnunu_*-setup.exe` (또는 `.msi`) | 설치 파일 실행 → 다음 → 완료 |
| 🐧 **Linux** (X11) | `Petnunu_*.AppImage` · `.deb` | AppImage: `chmod +x` 후 실행 · `.deb`: `sudo dpkg -i` |

### 처음 실행할 때
- **macOS** — **Developer ID 로 서명되고 공증(notarize)된** 앱이라 일반 앱처럼 더블클릭으로 바로 열리며, Gatekeeper 경고가 뜨지 않습니다.
- **Windows** — SmartScreen 이 *"Windows protected your PC"* 를 표시할 수 있습니다 → **More info → Run anyway** (아직 코드 서명 인증서를 구매하지 않았습니다).
- **Linux** — **X11** 에서 가장 잘 동작합니다. **GNOME Wayland** 를 쓴다면 **"Xorg/X11"** 세션으로 로그인해야 반려동물이 위치를 잡고 항상 맨 위에 떠 있을 수 있습니다.

**요구 사항:** macOS 14 (Sonoma)+ · Windows 10/11 · X11/XWayland 로 동작하는 Linux 데스크톱.

## ✨ 주요 기능

- 🐣 **데스크톱 펫 오버레이** — 걷고, 뛰고, 자고, 화면 가장자리를 오르내리며 매달리고, 커서를 따라다니고, 원하는 곳으로 끌어다 놓을 수 있습니다.
- 💖 **돌봄과 감정** — 밥 주기, 쓰다듬기, 놀아 주기, 재우기; happiness / energy / hunger / affection 지표.
- 🪙 **코인, 퀘스트, 업적** — 일일 미션, 업적, 코인 지갑.
- 🍅 **뽀모도로 & 집중 모드** — 휴식 / 물 마시기 / 눈 휴식 알림, 집중 통계(일간, 주간, 연속 기록).
- 🛒 **Pet Store** — 코인으로 더 많은 반려동물을 해금하세요.
- 🌱 **반려동물을 키워 레벨 업** + 커뮤니티 리더보드.
- 🎨 **Petnunu Studio** — 나만의 반려동물을 만들어 보세요.
- 📦 **직접 만든 펫 팩 가져오기**.
- 🖥️ **멀티 모니터**, 트레이 / 메뉴 막대, 온보딩, 사운드.

> 계정, 코인 지갑, 상점, 펫 팩은 **세 플랫폼 모두에서 공유**됩니다.

## ❓ FAQ

**이 앱은 오픈 소스인가요?**
빌드는 이곳에 공개적으로 배포되지만 소스 코드는 비공개입니다. 이 저장소는 앱 배포를 위한 곳입니다.

**Windows/Linux 빌드에도 macOS 의 모든 기능이 있나요?**
같은 서버, 계정, 지갑, 펫 팩 형식을 공유합니다. macOS 빌드(Swift)가 먼저 나왔고, Windows/Linux 빌드(Tauri)는 완전한 기능 동등성을 향해 발전하는 중입니다.

**제 언어를 지원하나요?**
웹은 22개 언어를 지원합니다. Windows/Linux 앱은 영어 + 베트남어를 제공하며, macOS 앱은 현재 영어만 지원합니다.

**비용이 드나요?**
다운로드와 사용은 무료입니다. 일부 인앱 아이템은 코인으로 구매할 수 있습니다.

**버그를 발견했거나 아이디어가 있나요?**
이 저장소에 **[Issue](https://github.com/hihi-team/pet-nunu-info/issues)** 를 남겨 주세요.
