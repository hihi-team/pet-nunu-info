# 🐾 Petnunu

**Ett virtuellt husdjur som bor på ditt skrivbord — macOS · Windows · Linux.**

fönster som svävar ovanför alla appar — styrt från systemfältet, med Pomodoro och
fokusläge så att jobbet känns lite lättare.

## ⬇️ Ladda ner

Hämta den senaste versionen från **[Releases](https://github.com/hihi-team/pet-nunu-info/releases/latest)** och välj sedan filen för ditt system:

| System | Fil | Installation |
|---|---|---|
| 🍎 **macOS** 14+ | `Petnunu-macOS-*.dmg` (eller `.zip`) | Öppna `.dmg` → dra **Petnunu.app** till **Applications** |
| 🪟 **Windows** 10/11 | `Petnunu_*-setup.exe` (eller `.msi`) | Kör installationsprogrammet → nästa → klart |
| 🐧 **Linux** (X11) | `Petnunu_*.AppImage` · `.deb` | AppImage: `chmod +x` och kör · `.deb`: `sudo dpkg -i` |

### Första starten
- **macOS** — appen är **signerad med ett Developer ID och notariserad**, så den öppnas som vilken vanlig app som helst (dubbelklick), utan varning från Gatekeeper.
- **Windows** — SmartScreen kan visa *"Windows protected your PC"* → **More info → Run anyway** (vi har ännu inte köpt något certifikat för kodsignering).
- **Linux** — fungerar bäst på **X11**. På **GNOME Wayland**, logga in i en **"Xorg/X11"**-session så att husdjuret kan placera sig själv och ligga kvar överst.

**Krav:** macOS 14 (Sonoma)+ · Windows 10/11 · ett Linux-skrivbord som kör X11/XWayland.

## ✨ Funktioner

- 🐣 **Skrivbordsöverlägg** — går, hoppar, sover, klättrar och hänger sig fast vid skärmkanterna, följer muspekaren, dra den vart du vill.
- 💖 **Omvårdnad & känslor** — mata, klappa, lek, stoppa om; statistik för happiness / energy / hunger / affection.
- 🪙 **Mynt, uppdrag & prestationer** — dagliga uppdrag, prestationer, myntplånbok.
- 🍅 **Pomodoro & fokusläge** — påminnelser om paus, vatten och ögonvila, fokusstatistik (dagligen, veckovis, streaks).
- 🛒 **Pet Store** — lås upp fler husdjur med mynt.
- 🌱 **Höj dina husdjurs nivå** + en topplista för communityn.
- 🎨 **Petnunu Studio** — skapa ditt eget husdjur.
- 📦 **Importera dina egna pet packs**.
- 🖥️ **Flera skärmar**, systemfält / menyrad, introduktion, ljud.

> Ditt konto, din myntplånbok, butiken och dina pet packs **delas mellan alla tre plattformarna**.

## ❓ Vanliga frågor

**Är appen öppen källkod?**
Byggena publiceras offentligt här; källkoden förblir privat. Det här förrådet finns för att distribuera appen.

**Har Windows/Linux-versionerna allt som macOS har?**
De delar samma server, konto, plånbok och format för pet packs. macOS-versionen (Swift) kom först; Windows/Linux-versionen (Tauri) är på väg mot full paritet.

**Stöds mitt språk?**
Webben talar 22 språk. Windows/Linux-appen levereras med engelska + vietnamesiska; macOS-appen har än så länge bara engelska.

**Kostar det något?**
Att ladda ner och använda appen är gratis. Vissa föremål i appen kan köpas med mynt.

**Hittat en bugg eller har du en idé?**
Öppna ett **[Issue](https://github.com/hihi-team/pet-nunu-info/issues)** i det här förrådet.
