## ⬇️ डाउनलोड

नवीनतम बिल्ड **[Releases](https://github.com/hihi-team/pet-nunu-info/releases/latest)** से लें, फिर अपने सिस्टम के हिसाब से फ़ाइल चुनें:

| सिस्टम | फ़ाइल | इंस्टॉल |
|---|---|---|
| 🍎 **macOS** 14+ | `Petnunu-macOS-*.dmg` (या `.zip`) | `.dmg` खोलें → **Petnunu.app** को **Applications** में खींचें |
| 🪟 **Windows** 10/11 | `Petnunu_*-setup.exe` (या `.msi`) | इंस्टॉलर चलाएँ → next → हो गया |
| 🐧 **Linux** (X11) | `Petnunu_*.AppImage` · `.deb` | AppImage: `chmod +x` फिर चलाएँ · `.deb`: `sudo dpkg -i` |

### पहली बार खोलने पर

- **macOS** — ऐप **Developer ID से साइन और notarize किया हुआ है**, इसलिए यह किसी भी सामान्य ऐप की तरह खुलता है (डबल-क्लिक), Gatekeeper की कोई चेतावनी नहीं आती।
- **Windows** — SmartScreen *"Windows protected your PC"* दिखा सकता है → **More info → Run anyway** (हमने अभी तक कोड-साइनिंग सर्टिफ़िकेट नहीं ख़रीदा है)।
- **Linux** — सबसे बेहतर सपोर्ट **X11** पर है। **GNOME Wayland** पर **"Xorg/X11"** सेशन में लॉग इन करें ताकि पेट अपनी जगह तय कर सके और हमेशा सबसे ऊपर बना रहे।

**ज़रूरतें:** macOS 14 (Sonoma)+ · Windows 10/11 · X11/XWayland पर चलने वाला Linux डेस्कटॉप।

## ❓ अक्सर पूछे जाने वाले सवाल

**क्या ऐप ओपन सोर्स है?**
बिल्ड यहाँ सार्वजनिक रूप से पब्लिश होते हैं; सोर्स कोड निजी रहता है। यह रिपॉज़िटरी ऐप बाँटने के लिए बनी है।

**क्या Windows/Linux बिल्ड में वह सब है जो macOS में है?**
सर्वर, अकाउंट, वॉलेट और पेट-पैक फ़ॉर्मैट सबमें एक ही हैं। macOS बिल्ड (Swift) पहले आया; Windows/Linux बिल्ड (Tauri) पूरी बराबरी की ओर बढ़ रहा है।

**क्या मेरी भाषा सपोर्ट होती है?**
वेब 22 भाषाएँ बोलता है। Windows/Linux ऐप अंग्रेज़ी + वियतनामी के साथ आता है; macOS ऐप फ़िलहाल सिर्फ़ अंग्रेज़ी में है।

**क्या इसका कोई ख़र्च है?**
डाउनलोड करना और इस्तेमाल करना मुफ़्त है। ऐप के भीतर कुछ आइटम कॉइन से ख़रीदे जा सकते हैं।

**कोई बग मिला / कोई सुझाव है?**
