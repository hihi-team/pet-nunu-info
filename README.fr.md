# 🐾 Petnunu

**Un animal de compagnie virtuel qui vit sur votre bureau — macOS · Windows · Linux.**

Votre compagnon se promène, saute, grimpe le long des bords de l'écran et fait la sieste dans
une fenêtre transparente qui flotte au-dessus de toutes vos applis — piloté depuis la barre
des menus, avec Pomodoro et mode focus pour rendre le travail un peu plus léger.

## ⬇️ Téléchargement

Récupérez la dernière version sur **[Releases](https://github.com/hihi-team/pet-nunu-info/releases/latest)**, puis choisissez le fichier correspondant à votre système :

| Système | Fichier | Installation |
|---|---|---|
| 🍎 **macOS** 14+ | `Petnunu-macOS-*.dmg` (ou `.zip`) | Ouvrez le `.dmg` → glissez **Petnunu.app** dans **Applications** |
| 🪟 **Windows** 10/11 | `Petnunu_*-setup.exe` (ou `.msi`) | Lancez l'installeur → suivant → c'est fait |
| 🐧 **Linux** (X11) | `Petnunu_*.AppImage` · `.deb` | AppImage : `chmod +x` puis lancez · `.deb` : `sudo dpkg -i` |

### Premier lancement
- **macOS** — l'app est **signée avec un Developer ID et notarisée** : elle s'ouvre comme n'importe quelle app (double-clic), sans avertissement Gatekeeper.
- **Windows** — SmartScreen peut afficher *« Windows protected your PC »* → **More info → Run anyway** (nous n'avons pas encore acheté de certificat de signature de code).
- **Linux** — le mieux pris en charge est **X11**. Sous **GNOME Wayland**, connectez-vous à une session **« Xorg/X11 »** pour que le pet puisse se positionner et rester au premier plan.

**Configuration requise :** macOS 14 (Sonoma)+ · Windows 10/11 · un bureau Linux tournant sous X11/XWayland.

## ✨ Fonctionnalités

- 🐣 **Pet en surimpression sur le bureau** — il marche, saute, dort, grimpe et s'accroche aux bords de l'écran, suit votre curseur, et se déplace où vous voulez au glisser-déposer.
- 💖 **Soins & émotions** — nourrissez-le, caressez-le, jouez avec lui, bordez-le ; statistiques happiness / energy / hunger / affection.
- 🪙 **Pièces, quêtes & succès** — missions quotidiennes, succès, porte-monnaie de pièces.
- 🍅 **Pomodoro & mode focus** — rappels de pause / hydratation / repos des yeux, statistiques de focus (jour, semaine, séries).
- 🛒 **Pet Store** — débloquez de nouveaux pets avec vos pièces.
- 🌱 **Faites monter vos pets en niveau** + classement communautaire.
- 🎨 **Petnunu Studio** — créez votre propre pet.
- 📦 **Importez vos propres packs de pets**.
- 🖥️ **Multi-écran**, barre des menus / zone de notification, prise en main guidée, sons.

> Votre compte, votre porte-monnaie, la boutique et vos packs de pets sont **partagés entre les trois plateformes**.

## ❓ FAQ

**L'app est-elle open source ?**
Les builds sont publiés ici publiquement ; le code source reste privé. Ce dépôt sert à distribuer l'app.

**Les versions Windows/Linux ont-elles tout ce que macOS propose ?**
Elles partagent le même serveur, le même compte, le même porte-monnaie et le même format de pack de pets. La version macOS (Swift) est arrivée en premier ; la version Windows/Linux (Tauri) avance vers une parité complète.

**Ma langue est-elle prise en charge ?**
Le web parle 22 langues. L'app Windows/Linux est livrée en anglais + vietnamien ; l'app macOS est pour l'instant uniquement en anglais.

**Est-ce payant ?**
Le téléchargement et l'utilisation sont gratuits. Certains objets dans l'app peuvent s'acheter avec des pièces.

**Un bug repéré / une idée ?**
Ouvrez une **[Issue](https://github.com/hihi-team/pet-nunu-info/issues)** dans ce dépôt.
