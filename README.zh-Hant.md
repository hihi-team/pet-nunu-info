## ⬇️ 下載

到 **[Releases](https://github.com/hihi-team/pet-nunu-info/releases/latest)** 取得最新版本，再依你的系統挑選檔案：

| 系統 | 檔案 | 安裝方式 |
|---|---|---|
| 🍎 **macOS** 14+ | `Petnunu-macOS-*.dmg`（或 `.zip`） | 開啟 `.dmg` → 把 **Petnunu.app** 拖進 **Applications** |
| 🪟 **Windows** 10/11 | `Petnunu_*-setup.exe`（或 `.msi`） | 執行安裝程式 → 下一步 → 完成 |
| 🐧 **Linux**（X11） | `Petnunu_*.AppImage` · `.deb` | AppImage：`chmod +x` 後執行 · `.deb`：`sudo dpkg -i` |

### 第一次啟動

- **macOS** —— 應用程式已**以 Developer ID 簽署並完成公證**，按兩下就能像一般 App 一樣開啟，不會出現 Gatekeeper 警告。
- **Windows** —— SmartScreen 可能顯示 *"Windows protected your PC"* → **More info → Run anyway**（我們還沒有購買程式碼簽署憑證）。
- **Linux** —— 在 **X11** 上支援最完整。若使用 **GNOME Wayland**，請登入 **「Xorg/X11」** 工作階段，寵物才能正確定位並保持最上層顯示。

**系統需求：** macOS 14 (Sonoma)+ · Windows 10/11 · 執行 X11/XWayland 的 Linux 桌面。

## ✨ 功能

- 🐣 **桌面寵物浮層** —— 走路、跳躍、睡覺，攀爬並攀附在螢幕邊緣，跟著你的游標跑，隨手拖到任何位置。
- 💖 **照顧與情緒** —— 餵食、摸摸、陪玩、哄睡；happiness / energy / hunger / affection 各項數值。
- 🪙 **金幣、任務與成就** —— 每日任務、成就、金幣錢包。
- 🍅 **Pomodoro 與專注模式** —— 休息 / 喝水 / 護眼提醒，專注統計（每日、每週、連續天數）。
- 🛒 **Pet Store** —— 用金幣解鎖更多寵物。
- 🌱 **養成寵物升級** + 社群排行榜。
- 🎨 **Petnunu Studio** —— 打造專屬於你的寵物。
- 📦 **匯入你自己的寵物包**。
- 🖥️ **多螢幕**、系統列 / 選單列、新手導覽、音效。

> 你的帳號、金幣錢包、商店與寵物包在**三個平台之間共用**。

## ❓ 常見問題

**這個 App 是開放原始碼嗎？**
建置版本會公開發佈在這裡；原始碼維持私有。這個儲存庫的用途是散布 App。

**Windows/Linux 版本有 macOS 版的全部功能嗎？**
它們共用同一套伺服器、帳號、錢包與寵物包格式。macOS 版（Swift）是最早的版本；Windows/Linux 版（Tauri）正一步步補齊到完全對等。

**有支援我的語言嗎？**
網頁端支援 22 種語言。Windows/Linux App 提供英文 + 越南文；macOS App 目前僅有英文。

**需要付費嗎？**
下載與使用都免費。部分 App 內的道具可以用金幣購買。

**發現問題 / 有好點子？**
在這個儲存庫開一則 **[Issue](https://github.com/hihi-team/pet-nunu-info/issues)**。
