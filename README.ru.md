# 🐾 Petnunu

**Виртуальный питомец, который живёт у вас на рабочем столе — macOS · Windows · Linux.**

## ⬇️ Скачать

Возьмите свежую сборку в разделе **[Releases](https://github.com/hihi-team/pet-nunu-info/releases/latest)** и выберите файл для своей системы:

| Система | Файл | Установка |
|---|---|---|
| 🍎 **macOS** 14+ | `Petnunu-macOS-*.dmg` (или `.zip`) | Откройте `.dmg` → перетащите **Petnunu.app** в **Applications** |
| 🪟 **Windows** 10/11 | `Petnunu_*-setup.exe` (или `.msi`) | Запустите установщик → далее → готово |
| 🐧 **Linux** (X11) | `Petnunu_*.AppImage` · `.deb` | AppImage: `chmod +x` и запустить · `.deb`: `sudo dpkg -i` |

### Первый запуск
- **macOS** — приложение **подписано Developer ID и нотаризовано**, поэтому открывается как обычное приложение (двойной клик), без предупреждений Gatekeeper.
- **Windows** — SmartScreen может показать *«Windows protected your PC»* → **More info → Run anyway** (сертификат для подписи кода мы пока не покупали).
- **Linux** — лучше всего работает на **X11**. В **GNOME Wayland** войдите в сессию **«Xorg/X11»**, чтобы питомец мог правильно позиционироваться и оставаться поверх остальных окон.

**Требования:** macOS 14 (Sonoma)+ · Windows 10/11 · рабочий стол Linux с X11/XWayland.

## ✨ Возможности

- 🐣 **Питомец поверх рабочего стола** — ходит, прыгает, спит, карабкается и цепляется за края экрана, следит за курсором, перетаскивается куда угодно.
- 💖 **Забота и эмоции** — кормите, гладьте, играйте, укладывайте спать; показатели happiness / energy / hunger / affection.
- 🪙 **Монеты, задания и достижения** — ежедневные миссии, достижения, кошелёк с монетами.
- 🍅 **Pomodoro и режим фокуса** — напоминания о перерыве, воде и отдыхе для глаз, статистика фокуса (за день, за неделю, серии).
- 🛒 **Pet Store** — открывайте новых питомцев за монеты.
- 🌱 **Прокачивайте питомцев** + таблица лидеров сообщества.
- 🎨 **Petnunu Studio** — создайте собственного питомца.
- 📦 **Импорт своих наборов питомцев**.
- 🖥️ **Несколько мониторов**, трей / строка меню, онбординг, звук.

> Аккаунт, кошелёк с монетами, магазин и наборы питомцев **общие для всех трёх платформ**.

## ❓ Частые вопросы

**Приложение с открытым исходным кодом?**
Сборки публикуются здесь открыто, а исходный код остаётся закрытым. Этот репозиторий нужен для распространения приложения.

**В сборках для Windows/Linux есть всё то же, что и в macOS?**
У них общий сервер, аккаунт, кошелёк и формат наборов питомцев. Сборка для macOS (Swift) появилась первой; версия для Windows/Linux (Tauri) постепенно догоняет её по функциям.

**Мой язык поддерживается?**
Веб говорит на 22 языках. Приложение для Windows/Linux — на английском и вьетнамском; версия для macOS пока только на английском.

**Это платно?**
Скачивание и использование бесплатны. Часть внутриигровых предметов можно купить за монеты.

**Нашли ошибку или есть идея?**
Создайте **[Issue](https://github.com/hihi-team/pet-nunu-info/issues)** в этом репозитории.
