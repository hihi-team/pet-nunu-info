## ⬇️ Muat Turun

Dapatkan binaan terkini daripada **[Releases](https://github.com/hihi-team/pet-nunu-info/releases/latest)**, kemudian pilih fail untuk sistem anda:

| Sistem | Fail | Pemasangan |
|---|---|---|
| 🍎 **macOS** 14+ | `Petnunu-macOS-*.dmg` (atau `.zip`) | Buka `.dmg` → seret **Petnunu.app** ke dalam **Applications** |
| 🪟 **Windows** 10/11 | `Petnunu_*-setup.exe` (atau `.msi`) | Jalankan pemasang → next → selesai |
| 🐧 **Linux** (X11) | `Petnunu_*.AppImage` · `.deb` | AppImage: `chmod +x` kemudian jalankan · `.deb`: `sudo dpkg -i` |

### Pelancaran pertama
- **macOS** — aplikasi ini **ditandatangani dengan Developer ID dan dinotarikan**, jadi ia dibuka seperti mana-mana aplikasi biasa (klik dua kali), tanpa amaran Gatekeeper.
- **Windows** — SmartScreen mungkin memaparkan *"Windows protected your PC"* → **More info → Run anyway** (kami belum membeli sijil penandatanganan kod).
- **Linux** — disokong paling baik pada **X11**. Pada **GNOME Wayland**, sila log masuk ke sesi **"Xorg/X11"** supaya haiwan peliharaan dapat menentukan kedudukannya dan sentiasa kekal di hadapan.

**Keperluan:** macOS 14 (Sonoma)+ · Windows 10/11 · desktop Linux yang menjalankan X11/XWayland.

## ✨ Ciri-ciri

- 🐣 **Tindanan haiwan peliharaan desktop** — berjalan, melompat, tidur, memanjat dan berpaut pada tepi skrin, mengikut kursor anda, seret ke mana-mana sahaja.
- 💖 **Penjagaan & emosi** — beri makan, belai, bermain, selimutkan; statistik happiness / energy / hunger / affection.
- 🪙 **Syiling, misi & pencapaian** — misi harian, pencapaian, dompet syiling.
- 🍅 **Pomodoro & mod fokus** — peringatan rehat / minum air / rehatkan mata, statistik fokus (harian, mingguan, streak).
- 🛒 **Pet Store** — buka lebih banyak haiwan peliharaan dengan syiling.
- 🌱 **Besarkan haiwan peliharaan untuk naik tahap** + papan pendahulu komuniti.
- 🎨 **Petnunu Studio** — cipta haiwan peliharaan anda sendiri.
- 📦 **Import pek haiwan peliharaan anda sendiri**.
- 🖥️ **Berbilang monitor**, dulang / bar menu, onboarding, bunyi.

> Akaun, dompet syiling, kedai dan pek haiwan peliharaan anda **dikongsi merentasi ketiga-tiga platform**.

## ❓ FAQ

**Adakah aplikasi ini sumber terbuka?**
Binaannya diterbitkan di sini secara umum; kod sumbernya kekal peribadi. Repo ini wujud untuk mengedarkan aplikasi.

**Adakah binaan Windows/Linux mempunyai semua yang ada pada macOS?**
Kesemuanya berkongsi pelayan, akaun, dompet dan format pek haiwan peliharaan yang sama. Binaan macOS (Swift) muncul dahulu; binaan Windows/Linux (Tauri) sedang menuju ke arah pariti penuh.

**Adakah bahasa saya disokong?**
Webnya bertutur dalam 22 bahasa. Aplikasi Windows/Linux disertakan bahasa Inggeris + Vietnam; aplikasi macOS buat masa ini hanya bahasa Inggeris.

**Adakah ia dikenakan sebarang bayaran?**
Memuat turun dan menggunakannya adalah percuma. Sesetengah item dalam aplikasi boleh dibeli dengan syiling.

**Jumpa pepijat / ada idea?**
Buka **[Issue](https://github.com/hihi-team/pet-nunu-info/issues)** dalam repo ini.
