## ⬇️ ดาวน์โหลด

โหลดเวอร์ชันล่าสุดได้ที่ **[Releases](https://github.com/hihi-team/pet-nunu-info/releases/latest)** แล้วเลือกไฟล์ให้ตรงกับระบบของคุณ:

| ระบบ | ไฟล์ | การติดตั้ง |
|---|---|---|
| 🍎 **macOS** 14+ | `Petnunu-macOS-*.dmg` (หรือ `.zip`) | เปิดไฟล์ `.dmg` → ลาก **Petnunu.app** ไปไว้ใน **Applications** |
| 🪟 **Windows** 10/11 | `Petnunu_*-setup.exe` (หรือ `.msi`) | เปิดตัวติดตั้ง → next → เสร็จ |
| 🐧 **Linux** (X11) | `Petnunu_*.AppImage` · `.deb` | AppImage: `chmod +x` แล้วเปิดใช้ · `.deb`: `sudo dpkg -i` |

### เปิดใช้ครั้งแรก

- **macOS** — แอป **เซ็นด้วย Developer ID และผ่าน notarize แล้ว** จึงเปิดได้เหมือนแอปทั่วไป (ดับเบิลคลิก) โดยไม่มีคำเตือนจาก Gatekeeper
- **Windows** — SmartScreen อาจขึ้นข้อความ *"Windows protected your PC"* → **More info → Run anyway** (เรายังไม่ได้ซื้อใบรับรองสำหรับเซ็นโค้ด)
- **Linux** — รองรับดีที่สุดบน **X11** ส่วนบน **GNOME Wayland** ให้ล็อกอินด้วยเซสชัน **"Xorg/X11"** เพื่อให้สัตว์เลี้ยงจัดตำแหน่งตัวเองและลอยอยู่บนสุดได้

**ความต้องการของระบบ:** macOS 14 (Sonoma)+ · Windows 10/11 · เดสก์ท็อป Linux ที่รัน X11/XWayland

## ✨ ฟีเจอร์

- 🐣 **โอเวอร์เลย์สัตว์เลี้ยงบนเดสก์ท็อป** — เดิน กระโดด นอน ปีนและเกาะขอบจอ เดินตามเคอร์เซอร์ ลากไปวางตรงไหนก็ได้
- 💖 **การดูแลและอารมณ์** — ให้อาหาร ลูบหัว เล่นด้วย กล่อมนอน พร้อมค่า happiness / energy / hunger / affection
- 🪙 **เหรียญ เควสต์ และความสำเร็จ** — ภารกิจประจำวัน achievement และกระเป๋าเหรียญ
- 🍅 **Pomodoro และโหมดโฟกัส** — เตือนพักเบรก ดื่มน้ำ พักสายตา พร้อมสถิติโฟกัส (รายวัน รายสัปดาห์ และสตรีค)
- 🛒 **Pet Store** — ปลดล็อกสัตว์เลี้ยงเพิ่มด้วยเหรียญ
- 🌱 **เลี้ยงสัตว์เลี้ยงให้เลเวลอัป** พร้อมกระดานจัดอันดับของคอมมูนิตี้
- 🎨 **Petnunu Studio** — สร้างสัตว์เลี้ยงของคุณเอง
- 📦 **นำเข้าแพ็กสัตว์เลี้ยงของคุณเอง**
- 🖥️ **รองรับหลายจอ**, ถาดระบบ / เมนูบาร์, การแนะนำการใช้งาน และเสียง

> บัญชี กระเป๋าเหรียญ ร้านค้า และแพ็กสัตว์เลี้ยงของคุณ **ใช้ร่วมกันได้ทั้งสามแพลตฟอร์ม**
