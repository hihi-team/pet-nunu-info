## ⬇️ Завантажити

Візьміть найновішу збірку в розділі **[Releases](https://github.com/hihi-team/pet-nunu-info/releases/latest)** й оберіть файл для своєї системи:

| Система | Файл | Встановлення |
|---|---|---|
| 🍎 **macOS** 14+ | `Petnunu-macOS-*.dmg` (або `.zip`) | Відкрийте `.dmg` → перетягніть **Petnunu.app** до **Applications** |
| 🪟 **Windows** 10/11 | `Petnunu_*-setup.exe` (або `.msi`) | Запустіть інсталятор → далі → готово |
| 🐧 **Linux** (X11) | `Petnunu_*.AppImage` · `.deb` | AppImage: `chmod +x` і запустити · `.deb`: `sudo dpkg -i` |

### Перший запуск
- **macOS** — застосунок **підписано Developer ID і нотаризовано**, тож він відкривається як звичайна програма (подвійний клік), без попереджень Gatekeeper.
- **Windows** — SmartScreen може показати *«Windows protected your PC»* → **More info → Run anyway** (сертифікат для підписання коду ми ще не купили).
- **Linux** — найкраще працює на **X11**. У **GNOME Wayland** увійдіть у сеанс **«Xorg/X11»**, щоб улюбленець міг правильно розташовуватися й лишатися поверх інших вікон.

**Вимоги:** macOS 14 (Sonoma)+ · Windows 10/11 · робоче середовище Linux з X11/XWayland.

## ✨ Можливості

- 🐣 **Улюбленець поверх робочого столу** — ходить, стрибає, спить, дереться та чіпляється за краї екрана, стежить за курсором, перетягується будь-куди.
- 💖 **Турбота та емоції** — годуйте, гладьте, грайтеся, вкладайте спати; показники happiness / energy / hunger / affection.
- 🪙 **Монети, завдання та досягнення** — щоденні місії, досягнення, гаманець із монетами.
- 🍅 **Pomodoro та режим фокусу** — нагадування про перерву, воду й відпочинок для очей, статистика фокусу (за день, за тиждень, серії).
- 🛒 **Pet Store** — відкривайте нових улюбленців за монети.
- 🌱 **Вирощуйте улюбленців до нових рівнів** + таблиця лідерів спільноти.
- 🎨 **Petnunu Studio** — створіть власного улюбленця.
- 📦 **Імпорт власних наборів улюбленців**.
- 🖥️ **Кілька моніторів**, лоток / рядок меню, онбординг, звук.

> Обліковий запис, гаманець із монетами, крамниця та набори улюбленців **спільні для всіх трьох платформ**.

## ❓ Часті запитання

**Чи застосунок має відкритий код?**
Збірки публікуються тут відкрито, а вихідний код лишається закритим. Цей репозиторій існує для розповсюдження застосунку.

**Чи мають збірки для Windows/Linux усе те саме, що й macOS?**
У них спільні сервер, обліковий запис, гаманець і формат наборів улюбленців. Збірка для macOS (Swift) з'явилася першою; версія для Windows/Linux (Tauri) поступово наздоганяє її за функціями.

**Чи підтримується моя мова?**
Веб говорить 22 мовами. Застосунок для Windows/Linux — англійською та в'єтнамською; версія для macOS наразі лише англійською.

**Чи це коштує грошей?**
Завантаження та використання безкоштовні. Частину предметів у застосунку можна придбати за монети.

**Знайшли помилку чи маєте ідею?**
Створіть **[Issue](https://github.com/hihi-team/pet-nunu-info/issues)** у цьому репозиторії.
